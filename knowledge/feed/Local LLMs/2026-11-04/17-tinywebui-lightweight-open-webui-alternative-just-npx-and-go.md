While we cant quite match the feature set of Open WebUI, TinyWebUI can be installed with a simple npx command, "npx tinywebui". It comes with tinysearch and tinycontext preinstalled for fully local web search and memory, and can support multiple users with per user isolation. Also has other useful stuff like automations and a stats dashboard built in, and ofc you can always extend it with any mcp server you desire. Give it a try, it pairs well with local models, the smallest we tested that was able to use it flawlessly was lfm3 1.7B ( https://huggingface.co/LiquidAI/LFM3-1.7B ).

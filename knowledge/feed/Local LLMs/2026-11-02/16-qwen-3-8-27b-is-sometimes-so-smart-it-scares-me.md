For fun, I gave Qwen 3.8 27b a physics problem involving some heavy math. A little bit into its reasoning, Qwen took a look at its tools, found that it had access to Blender via blender mcp - and that it could write and execute arbitrary python code through that. So it engaged Blender's python support to write itself bits of python code to do its math faster. You really have to tell this model what NOT to do sometimes... I've never seen anything like this from a local model before. submitted by /u/Balloon_Fan [link] [comments]

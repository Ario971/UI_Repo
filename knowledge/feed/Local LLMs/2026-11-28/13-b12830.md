chat : Allow K2 Horizon tool call during thought (#32993) Allow tool calls that would otherwise appear inside reasoning/thinking blocks for K2 Horizon. K2 Horizon models can emit tool calls without closing the thinking block. Without this fix the parser would only stop on explicit end tag, and the tool call was lost without executing. With this PR we now end reasoning before the tool call starts. In short, when reasoning mentions ` `, we end reasoning there. My tests cover this case at medium and high effort. This fixes #32972, and is the same pattern as #32232 (Gemma4) and #32271 (Ministral-3). - I have read and agree with the [contributing guidelines](https://github.com/ggml-org/llama.cpp/blob/master/CONTRIBUTING.md) I have used Opus to run and score benchmarks, help find the K2 parser, draft the fix and test, and see how others have resolved this for other models. I have carefully examined all changes and tested with my local benchmarks. I have used Sol to code review twice.

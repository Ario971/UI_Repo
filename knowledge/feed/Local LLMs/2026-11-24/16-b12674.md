opencl: fetch the Adreno binary kernel library at configure time for Windows on Snapdragon (#31759) * opencl: fetch the Adreno binary kernel library at configure time Make GGML_OPENCL_USE_ADRENO_BIN_KERNELS an option, default ON, and add GGML_OPENCL_ADRENO_BIN_KERNELS_FETCH, default ON. On Windows, CMake downloads the pinned adreno-opencl-kernels release from the Qualcomm Software Center, verifies its SHA256, and copies the DLL and its license next to the executables. A failed download is only a warning; the backend then uses its builtin kernels. The opencl-adreno release job turns the fetch off, since it ships only ggml-opencl.dll. * opencl: fetch the Adreno binary kernel library only on ARM64 The library is built for Windows on ARM64 only. * opencl: add download timeout and better handle output dir Assisted-by: Codex * opencl: add .txt to license file Assisted-by: Codex --------- Co-authored-by: Li He **Website:** -

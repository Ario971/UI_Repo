Hi HN, Rouler is "rules for your routes". It allows you to steer network traffic across multiple network interfaces on Windows. For example: - Run Tailscale, Mullvad and OpenVPN official clients simultaneously. - Use Rouler to send Slack via the OpenVPN connection, Chrome + an IP range via Tailscale and a torrent client via Mullvad. Rouler is VPN agnostic, so you can "split-tunnel" with anything that sets up a windows network interface. I'm an independent developer from Australia and have been working on Rouler for a bit over a year. It's been a challenging project to say the least, but I'm really happy with how it's turning out. I have spent a great deal of time building and throwing things away, starting over, belting the initial poc into something that I find intuitive... hopefully others do too! I've done all the testing, fixing and improving I can, so now it's open for public beta. I'd love to hear your feedback... and there are some specific points I'm interested in hearing about listed on the Rouler website. Please reply with any questions you might have. Thanks for reading! Brendan p.s. Rouler is "built in Rust" TM ;-) --- On AI (skip if you're sick of hearing about it): Since AI is the hot topic and people are naturally cautious about it, I'll add some quick notes about it, specifically about the driver development as that's the key thing to get right. The driver is hand written and every detail has been poured over many times over. I spent somewhere around 6-9 months manually building and testing just the driver, staring at Dbgview logs, wireshark logs, windows route tables, restarting VM's back to their snapshot and manually copying things across to start again. That's not always the most efficient way of doing things, but it's the way it had to be done. If I had tried to vibe code it Rouler simply wouldn't exist. I did try to lean on AI at times, but it constantly sent me in the wrong direction, told me things weren't possible, tried to take shortcuts and implement poor performing trade-offs. It also loved to hallucinate the windows api. Keep in mind this was around the Opus 4.1 - 4.6 days. Outside of the driver, in user mode land, AI has crept more and more into my workflow. I've had a lot of success utilising the latest models in the app in particular, and I purposefully separated the UI and core logic so I'm able to quickly iterate on the UI. I've also found AI very useful for scripting and refactoring. It has built some great scripts that would've taken me days or weeks to build and fine tune.

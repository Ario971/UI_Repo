I'm new here, and little nervous about posting, but here goes. I'm not a newbie. I started programming in BASIC when my dad bought home a TRS-80 Model I in 1980, when I was 16. Other than a 9-year stint as active duty military, I've spent 46 years either personally or professionally working in tech. I've programmed in RPG using punch cards for an IBM /System360, and COBOL on a DEC pdp 11/34. I've worked professionally with VB, C#, SQL Server, ColdFusion, PHP, and more. I've seen a lot of technologies come and go. So this ain't the first time I've jogged around this track. Here's the problem I wanted to solve: I hate WordPress. I mean, as a concept, it's fine, but I used to have a fairly popular motorcycle blog on WP that got trashed by hackers. I've also run into that problem with customers. When hackers find a wordpress site, they just bang on it like a drum. It's a pain. It's also a pain just to manage it, with a wild-west plugin system where plugins constantly fall in and out of compatibility. I'm also not a huge fan of PHP, but since it comes stock with pretty much every shared hosting service, where a lot of my web work is done, it's kind of the default for doing web stuff. Back in about 2006 or so, I built my own blogging software, which I called .Blog, as an ASP.NET deal in C#. It took me about 6 months to build, start to finish. I didn't have time to keep up with it, which is why I defaulted back to WP sometime around 2014. I migrated to Grav when I ran across it (I guess around 2020 or so), and I liked that. But Grav ran into some issues, and development on it really slowed. In the past year or so, the company I work for has been delving into using Claude Code, and I got an idea. What if I could just use Claude Code to build a CMS that has everything I want, and nothing I don't? This project is the result of that idea. I designed the specifications for what I wanted it to do, and let Claude Code handle the actual code writing. I started with a flat-file, markdown-based flat-file CMS, and iterated on that. Fiddling around with markdown files and folders started to get tedious, so I moved towards SQLite as the back-end, to create a system as self-contained and easy to use as possible. This project is, I think, the final result of that idea. This project, from start to finish, took about 2 weeks to build using Laravel/Filament/PHP with Claude Code, compared to the 6 months it took to build .Blog by hand, 20 years ago. Cripes, I'm old. Personally, I'm pretty pleased with how this project turned out. I'm running two public websites on it. I'd be interested to hear what others think.

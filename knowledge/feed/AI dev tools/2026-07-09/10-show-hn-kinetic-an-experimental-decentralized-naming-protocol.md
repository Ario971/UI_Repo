Hi HN, I started this while working on another project. I needed peer-to-peer connections and realized I still depended on domains, so I started wondering if there was another way to do naming. This became Kinetic. It's an experimental naming protocol written in Rust. The idea is to use VDFs for name registration while libp2p and Kademlia handle discovery. Things are still changing a lot and I'm still testing different ideas. One thing I'm currently struggling with is the economic side. If users don't pay for names, how does an open protocol sustainably fund long-term development? I'd be interested in hearing different perspectives on that. I'd appreciate technical feedback on the protocol and any obvious flaws in the design.

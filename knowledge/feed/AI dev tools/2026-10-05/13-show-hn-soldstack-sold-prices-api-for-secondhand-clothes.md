Soldstack is a site for developers to get the buy or sell value of a product mainly on Poshmark right now. The reason I built this is because eBay sold data got locked behind a login, and Poshmark data is messy and often over a year old. So I wanted to create something that makes it easier to access this data. When I was making this, I had to be careful with cleaning out the data. For example, if one searched nike dunk low, they would get nike dunk lows, toddler and kid's sizes (which go much cheaper), bundles, other shoes, duplicates, and high outliers. But if you average all that, the price would be inaccurate. Things to try include the price guide, the fee calculator, which all need no sign up. The Google Sheets formula does need a signup however. I'd love feedback on whether I should expand this to Mercari or if something looks off. Thanks!

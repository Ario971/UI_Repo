TermDOM renders a real DOM styled with real CSS to terminal cells. You build a document with createElement or innerHTML, or any frontend web framework, and it automatically produces colored ANSI output, with browser-style layout, text wrapping and flexbox included. The library can also be used to translate HTML to static ANSI. Full disclaimer: This project was started a year ago and written entirely by Claude.

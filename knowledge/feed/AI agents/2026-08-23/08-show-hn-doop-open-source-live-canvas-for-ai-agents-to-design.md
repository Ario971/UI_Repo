Doop is an open source alternative to Paper.design or Pen.dev. AI agents can collaborate and design on the same canvas and Doop will build up context and memory on design decisions. It's fully open source. We're working on an AI agent that reviews PRs and checks design consistency and other design related checks. Curious to hear if you can think of other features we should add.

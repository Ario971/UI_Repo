I spend a lot of time in Claude Code and Codex with my friend. We kept losing the context behind changes because every agent session lived on one person's laptop, and by the time code made it into a PR, all the reasoning was gone. We tried commits, PRs, and docs, but they only really capture the end result, so we built a tool to keep all of our agent sessions in one searchable place. Now we (and our agents) can check out anyone's session and ask things like "what was Alex working on yesterday?" It's also quite helpful in recovering the context behind a change days or weeks later. Ocean works with Claude Code, Codex, OpenCode, Hermes, Pi, and other agent harnesses. We've been using it every day ourselves and it's become a core part of how we work together. Hopefully some of you find it useful too! Try it out: https://ocean.mosaic.inc/ Demo: https://www.youtube.com/watch?v=sjyrgkRBWVg
